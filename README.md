# Genoxidil - Saúde Celular e Longevidade

Site oficial do Genoxidil, suplemento de regeneração celular com ativação da proteína Nrf2.

**URL**: https://genoxidil.blog

## Tecnologias Utilizadas

Este projeto foi desenvolvido com:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desenvolvimento Local

```sh
# Clone o repositório
git clone <YOUR_GIT_URL>

# Navegue até o diretório do projeto
cd <YOUR_PROJECT_NAME>

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## Deploy

O deploy é feito automaticamente via GitHub Actions para a Hostinger.
